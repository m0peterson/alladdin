# Проверка изображения T02

PASS — Godot 4.7.2 stable standard (ed1daf0bf), Compatibility, Xorg dummy
и Mesa llvmpipe. Это кадры настоящего главного viewport 320×180.
Просмотрены четыре направления idle/walk, обе фазы шага и линия стоп,
читаемая кириллица, отсутствие размытия и пересечения с заголовком у северной стены.

- [arena.png](arena.png) — площадка сразу после запуска.
- [directions.png](directions.png) — фрагменты 20 кадров: строки вниз, влево,
  вправо, вверх; колонки idle и четыре кадра цикла walk. Монтаж увеличен
  строго вдвое через nearest, персонажи не дорисованы. Их экранные положения
  различаются, поскольку снималась настоящая ходьба.
- [north-edge.png](north-edge.png) — упор в северную границу.

Повторить на машине с дисплеем и OpenGL 3.3, после `./tools/check.sh`:

```sh
timeout 60s ./tools/godot.sh --audio-driver Dummy --fixed-fps 60 \
  --script res://tests/capture_movement.gd
```

В облаке при уже запущенном Xorg использованы `DISPLAY=:99`
и `LIBGL_ALWAYS_SOFTWARE=1`. Скрипт сохраняет 22 исходных PNG
в `.godot/t02-review/`. При headless он возвращает BLOCKED с кодом 1.
Он подаёт ввод тому же контроллеру игрока; анимации не подменяются кадрами вручную.

Скриншоты подтверждают изображение, а не субъективное ощущение управления.
Для игрового ревью: `./tools/godot.sh`, WASD/стрелки, все стороны стен,
движение вдоль стены и остановка после каждого направления. Окончательная графика — T18.
