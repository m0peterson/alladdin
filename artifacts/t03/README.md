Захват фиксирует положения для просмотра перекрытий; это не доказательство
проходимости. Маршруты проходят отдельным сценарием через настоящий ввод
и физику без телепорта между точками пути: `./tools/test.sh`.

Повторить на машине с дисплеем и OpenGL 3.3 после `./tools/check.sh`:

```sh
timeout 60s ./tools/godot.sh --audio-driver Dummy --fixed-fps 60 \
  --script res://tests/capture_bazaar.gd
```

В облаке при запущенном Xorg использованы `DISPLAY=:99`
и `LIBGL_ALWAYS_SOFTWARE=1`. Исходные PNG сохраняются в `.godot/t03-review/`.
При headless захват сообщает BLOCKED и завершается с кодом 1.
Геометрия и маркеры временные. Эти кадры не закрывают T18 и не подтверждают
ощущение управления; экспорт и запуск на Windows не выполнялись.
