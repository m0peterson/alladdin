## Повторение и логи

```sh
./tools/check.sh
./tools/test.sh
DISPLAY=:99 LIBGL_ALWAYS_SOFTWARE=1 timeout 60s ./tools/godot.sh \
  --audio-driver Dummy --fixed-fps 60 --script res://tests/check_t05_t10.gd \
  -- --capture-review
DISPLAY=:99 LIBGL_ALWAYS_SOFTWARE=1 T09_CAPTURE_DIR=res://.godot/t09-review \
  timeout 60s ./tools/godot.sh --audio-driver Dummy --fixed-fps 60 \
  --script res://tests/check_bandit.gd -- --capture-bandit
```

Последним двум командам нужен дисплей и OpenGL 3.3. Использованы имеющийся
Xorg dummy `:99` и Mesa llvmpipe; V-Sync недоступен у виртуального дисплея.
Общий capture с headless возвращает BLOCKED и код 1. Кадры общего сценария
сохраняются в `.godot/t05-t10-review/`, дуэли — в `T09_CAPTURE_DIR`.

- PASS — [checks.log](checks.log): импорт/старт/настройки.
- PASS — [tests.log](tests.log): T02–T10 и общая интеграция, timeout на каждый сценарий.
- PASS — [render.log](render.log): общий сценарий с настоящим рендером.
- PASS — [bandit-render.log](bandit-render.log): рендер тестовой дуэли и восстановления.
- PASS — документы/ссылки/зависимости, `bash -n tools/test.sh`, `git diff --check`.

NOT RUN в headless-логах о читаемости относится только к headless-запуску;
изображение проверено отдельно двумя графическими командами выше.
NOT RUN — субъективное ощущение боя пользователем, экспорт и Windows.
Непроверенных обязательных критериев T05–T10 нет.

## Ручной маршрут и ограничения

Новая игра → I → выбрать лепёшку (при полном здоровье она не тратится) → Esc.
На базаре E у каждого торговца → купить/продать → Esc. Затем на восток
к бандиту → увидеть жёлтую подготовку → Q → ответить ударом после его атаки.
После урона открыть I и съесть лепёшку; при поражении сверить старт/деньги.
Посмотреть патрули базара, переулка и склада; стража пока не преследует.

Скупщик только разговаривает; сундук пуст. Лампа и краденые экземпляры есть
в данных/тестах, их получение в игре относится к следующим карточкам.
Бандит не строит глобальный путь и не блокирует игрока телом. Стражника
можно остановить, стоя на его маршруте; после освобождения пути он продолжает.
