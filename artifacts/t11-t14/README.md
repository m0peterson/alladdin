## Повторение

```sh
./tools/check.sh
./tools/test.sh
DISPLAY=:99 LIBGL_ALWAYS_SOFTWARE=1 timeout 60s ./tools/godot.sh \
  --audio-driver Dummy --fixed-fps 60 --script res://tests/check_t11_t14.gd \
  -- --capture-review
```

Последняя команда требует настоящий дисплей/OpenGL 3.3; headless с capture
возвращает BLOCKED и код 1. Кадры сохраняются в `.godot/t11-t14-review/`.
Логи: [checks.log](checks.log), [tests.log](tests.log), [render.log](render.log).
Ошибки/таймаут дают ненулевой код. Предупреждение V-Sync виртуального дисплея
не мешает рендеру. PASS — документы/ссылки, shell syntax и diff --check.

## Воспроизводимые маршруты

Штатный ввод, физика и патрули; нет телепортации между точками, изменения
стражи, видимости или времени F. Для независимых проверок окон/отказов
в начале сценария позиции задаются явно.

С тревогой: принять заказ, затем `(240,368) → (240,312) → (504,312) →
(504,190) → (544,190) → (544,176)`, F. Возврат в обход стражи: `(568,176) →
(568,136) → (504,136) → (504,188) → (504,312) → (240,312) → (240,368) →
(112,368)`. Зафиксирован CHASE, лампа не теряется, тревога истекает.

Скрытно, до заказа: `(240,368) → (240,312) → (400,312) → (400,224)`;
Shift к `(504,224)`. Дождаться стражника на нижнем отрезке склада, идущего
влево при x=500–515, затем Shift к `(504,176)`, F, Shift назад через
`(504,224) → (400,224)`. Возврат: `(400,312) → (240,312) → (240,368) →
(112,368)`. Ожидание ограничено 800 кадрами. CHASE отсутствует на всём пути;
ранняя лампа учитывается при явном принятии, затем выдаётся одна награда.

## Ограничения

Непроверенных обязательных критериев T11–T14 нет. NOT RUN — субъективное
ощущение боя пользователем, экспорт и Windows; они вне этого пакета.
Нет глобального navigation: стража идёт с коллизиями к известному месту,
ограниченно ищет и возвращается по следу; динамическая преграда может
задержать возврат при снятой тревоге. Стража пока не наносит урон.
Графика временная; сохранений и смены дня нет. Меню теряет игру.
После ревью/merge следующая по порядку карточка — T15 отдельным запросом.
Работа остановлена на T14.
