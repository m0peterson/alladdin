# Короткие промпты для отдельных запусков

Документы уже должны быть в репозитории. Полный исходный промпт каждый раз вставлять не нужно.

## Конкретная карточка

Выполни только T02 из docs/TASKS.md. Прочитай AGENTS.md, ROADMAP.md, docs/STATE.md и критерии T02. Проверь зависимости. Реализуй только объём T02, запусти относящиеся проверки. Если обязательные критерии выполнены, включи галочку T02 в ROADMAP.md в тот же diff. Обнови docs/STATE.md и подготовь PR «[T02] Движение Аладдина». Если критерии не выполнены, оставь галочку пустой и назови блокер/остаток. Следующую карточку не начинай.

Замени T02 и заголовок на нужный ID. Если требуется настоящий PR, используй доступный штатный механизм. Отсутствующий инструмент открытия PR не даёт разрешения заявлять, что PR создан.

## Одна следующая готовая карточка

Прочитай AGENTS.md, ROADMAP.md и docs/STATE.md. Выбери одну открытую карточку из docs/TASKS.md, у которой закрыты зависимости в базовой ветке; обычно с наименьшим номером. Назови выбранный ID. Выполни только её, проверь текущие критерии, обнови roadmap в том же diff и docs/STATE.md. Подготовь один PR. При незакрытой обязательной проверке оставь checkbox пустым. Затем остановись, следующую карточку не бери.

## Продолжение частичной карточки

Продолжи только T__ с текущего состояния ветки/PR. Прочитай фактический остаток в docs/STATE.md. Не начинай заново работающие части и не выполняй соседние карточки. Исправь блокер/остаток, проверь критерии T__. Закрой checkbox в том же PR только при выполнении всех обязательных пунктов. Обнови состояние и остановись.

## Замечания по текущему PR

Исправь только замечания ниже в текущем PR для T__:
[ВСТАВИТЬ ЗАМЕЧАНИЯ]

Сначала воспроизведи проблему доступным способом. Исправь её и проверь затронутые сценарии. Сохрани рабочие системы и прогресс save. Пересмотри галочку, если исправления выявили незавершённый обязательный пункт. Обнови docs/STATE.md. Следующую карточку не выполняй.

## Если карточка оказалась слишком большой

Раздели только T__ на небольшие дочерние карточки со стабильными ID и критериями. Обнови docs/TASKS.md и ROADMAP.md; родителя оставь открытым. Саму реализацию всех частей в этой задаче не начинай. Подготовь небольшой PR с уточнением плана.
