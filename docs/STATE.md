# Фактическое состояние

Это стартовый пакет требований. Игровой код, проверки и сборки ещё не созданы.

## Прогресс

Единственный источник статуса: ROADMAP.md в выбранной базовой ветке. В этом пакете все карточки TODO. ID текущего задания при первом запуске: T00.

## Что работает

Пока только документы проекта.

## Как запустить

Пока игрового проекта нет. После T01 здесь должна появиться одна актуальная команда запуска.

## Последняя работа

Заполнять агентом: ID карточки, конкретный результат, существенные решения. Не вести многословный журнал каждого действия.

## Проверки

Заполнять: команда и PASS / FAIL / NOT RUN / BLOCKED с коротким выводом. Ссылки на большие логи можно хранить отдельно.

## Блокеры и проблемы

Указать фактические проблемы текущего состояния. Для BLOCKED оставить checkbox открытым.

## Следующая подходящая задача

Сначала T00. После merge выбирать один ID с готовыми зависимостями. Не запускать его автоматически.

## Правило обновления

Обновлять этот файл в каждом PR. Хранить краткое текущее состояние, а не копию roadmap и всего ТЗ. Не записывать неизвестный PR номер, SHA или результаты непроведённых проверок.
