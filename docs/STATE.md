Пока игрового проекта нет. После T01 здесь должна появиться одна актуальная команда запуска.

- PASS — одноразовая проверка Python: обязательные документы и шаблон существуют; 21 ID, зависимости и якоря согласованы; локальные ссылки корректны; циклов зависимостей нет; отмечена только T00.

## Блокеры и проблемы

По критериям T00 блокеров нет. Автоматическое открытие PR блокирует сетевой прокси: CONNECT к api.github.com получает HTTP 403 Forbidden. Изменения можно отправить через Git и открыть PR из отдельной ветки в интерфейсе GitHub.
