# Фактическое состояние

Запускается связный квартал базара 640×432 с Аладдином, стенами, прилавками
и статичными маркерами NPC. Есть движение и два разных входа на склад.

## Прогресс

Источник статуса: ROADMAP.md. T00–T02 влиты в main (PR #1–#3).
В текущем PR предложена галочка только T03; она станет принятой после merge.
T04–T20 остаются открытыми. T04 не начата.

## Что работает

Godot 4.7.2 stable standard (ed1daf0bf), Compatibility, viewport 320×180,
nearest filtering и целочисленное увеличение. WASD/стрелки, нормализованная
диагональ, четыре направления idle/walk и общий нижний origin у ног сохранены.
Камера следует за игроком без сглаживания и ограничена кварталом.

Есть базар с двумя торговцами, склад, переулок, скупщик со стартом рядом
и площадка боя. Прямой маршрут идёт по южной дороге через главный вход;
обход огибает длинное здание с севера и проходит через переулок в боковой вход.
Стены, прилавки и пять маркеров NPC блокируют ноги и сортируются вместе с героем
по Y. У объектов и зон есть стабильные строковые ID.

## Как запустить

`./tools/godot.sh`. При отсутствии движка — `./tools/bootstrap-godot.sh`.
Проверки: `./tools/check.sh`, затем `./tools/test.sh`.
Маршруты и управление — в README.md; кадры и повторение визуального ревью —
в artifacts/t03/README.md. Прежняя площадка T02 сохранена как тестовая сцена.

- PASS — `./tools/check.sh`: импорт, запуск карты, настройки viewport/фильтрации.
- PASS — `./tools/test.sh`: регрессия T02; два непрерывных маршрута на склад,
  все пять зон и возврат к скупщику; 12 сторон стен/прилавков, пять NPC,
  четыре границы, скольжение и угол; общая опора ног и структура Y-sort.
- PASS — отрицательные проверки в изолированной копии: закрытый главный вход
  и отключённые столкновения обнаружены с кодом 1.
- PASS — отдельное визуальное ревью: Xorg dummy, Compatibility/Mesa llvmpipe;
  просмотрены девять игровых кадров 320×180 и обзор 640×432 с пикселями 1:1.
  Все зоны, кириллица, ноги и перекрытия перед/за стеной и прилавком проверены.

- PASS — документы, ссылки/якоря, ID и зависимости; шаблон PR сохранён.
  Предлагается галочка только T03. `bash -n` и `git diff --check` без ошибок.
- NOT RUN — субъективная оценка управления пользователем, экспорт и Windows.
  Это не обязательные критерии T03; непроверенных обязательных пунктов нет.
