# Фактическое состояние

Есть минимальный Godot-проект со стартовой сценой. Игровые механики и сборки предстоят в следующих карточках.

## Прогресс

Единственный источник статуса: ROADMAP.md в выбранной базовой ветке. T00 влита в main. В текущем diff предложено завершение T01; оно станет принятым после merge. Следующие карточки остаются открытыми.

## Что работает

Стартовая сцена scenes/start.tscn открывается в Godot 4.7.2 stable standard. Настроены Compatibility, viewport 320×180, nearest filtering, целочисленное увеличение и начальное окно 960×540. Документы и шаблон PR сохраняют правило одной карточки.

## Как запустить

В корне репозитория: ./tools/godot.sh. При первом запуске без подходящего движка: ./tools/bootstrap-godot.sh. Подробности и проверка — в README.md.

## Последняя работа

T01: добавлены project.godot, одна статичная стартовая сцена, .gitignore и команды установки, запуска и импорта. Использован официальный Godot 4.7.2 stable standard (ed1daf0bf); установленная ранее 4.6.3 не заменялась. Bootstrap проверяет официальный SHA-256 и переиспользует уже доступную нужную версию. Экспортные шаблоны не устанавливались.

## Блокеры и проблемы

По критериям T01 блокеров нет. На виртуальном дисплее Mesa сообщает о недоступном V-Sync; запуск и получение изображения работают. Графическое ревью здесь касается только стартовой сцены. GitHub API доступен.
