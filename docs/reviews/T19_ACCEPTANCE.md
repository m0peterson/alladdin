Известные Low-ограничения: инициализация доверенного JSON-контента не имеет
полной проверки схемы/уникальности ID; недоверенный save проходит отдельную
валидацию. При следе стражника длиннее 4096 точек save отклоняется до конца
возврата: это предел сохраняемости долгого CHASE, а не доказательство корректного
сохранения любого игрового состояния. Обычный сценарий активной тревоги проверен,
загрузка не снимает её. Эти ограничения требуют отдельной ограниченной доработки.
