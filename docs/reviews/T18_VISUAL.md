## Изменения

Четыре собственных NPC-атласа переиспользуют собственный силуэт игрока T02:
16×24, четыре направления, idle и два шага. `CharacterVisual` рисует настоящие
направление/движение и состояние, не изменяет правила. Guard/bandit изменены
только в `_draw`; коллизии, AI, положение опорной точки и пути сохранены.
Статичные торговцы/скупщик смотрят вниз, стража/бандит следуют своему направлению.

Игрок узнаваем по красной шапочке/пурпуру/белым штанам; торговец — по светлой
чалме/бирюзе/кошелю, скупщик — по капюшону/цепи, стража — по синему мундиру,
шлему/копью, бандит — по красной маске/клинку/коричневым штанам. Светлый вопрос
передаёт подозрение, красный знак — погоню, бирюзовый вопрос — поиск; при возврате
к патрулю знак исчезает. Русский HUD дополнительно называет состояние.

Земля получила фиксированную фактуру, переулок — каменную мостовую, торговые
места — ковры, стены — кладку, прилавки — обводку/товар. Сундуки имеют замок
и окантовку. Конечная добыча показывает существующую иконку лампы/шёлка;
после опустошения иконка исчезает, внутренняя часть темнеет. Рисование только
читает `TheftTarget.stock`. Семь собственных товарных SVG 16×16 сохранены:
их тёплые света/тёмные границы согласуются с палитрой комплекта.

Существующие дуга направленного удара, рывок, красный импульс урона, телеграф
бандита и читаемый русский GUI сохранены. Тёмные фоны/тёплый текст окон уже
соответствуют комплекту; изменения game/menu не требуются. Новые save/day окна
интегратор проверяет отдельно. Происхождение, палитра и воспроизведение:
[assets/ATTRIBUTION.md](../../assets/ATTRIBUTION.md).

## Проверки и пределы

PASS: импорт, `./tools/check.sh`, `./tools/test.sh` T02–T14, headless ресурсный
контракт `tests/check_visual.gd`, три настоящих графических сценария, повторная
генерация тех же байтов PNG, `git diff --check`. Команды/логи:
[artifacts/t15-t19/t18/README.md](../../artifacts/t15-t19/t18/README.md).

T18 capture задаёт позиции для Y-sort и направления игрока, временно останавливает
физику акторов. Для поиска камера центрируется на настоящем стражнике;
публичный `report_crime` получает его текущую точку как известную позицию,
затем AI сам проходит CHASE→SEARCH→PATROL при скрытом игроке. Это визуальная
фикстура состояния. Настоящая замеченная кража и скрытный маршрут отдельно
проверены `check_t11_t14.gd` через игровые операции.
