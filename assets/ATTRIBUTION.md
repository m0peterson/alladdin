# Происхождение ассетов

`characters/aladdin.png` — собственный временный пиксельный спрайт, созданный
для этого проекта в T02. Сторонние изображения не использованы. Исходник:
`tools/generate_player.py` (Python 3, только стандартная библиотека).
Готовый PNG включён в репозиторий; Python для запуска игры не нужен.

Кадр 16×24; колонки: idle, шаг левой ногой, шаг правой ногой.
Строки: вниз, влево, вправо, вверх. Нижняя линия стоп одинакова: y=23,
точка опоры сцены игрока — нижний центр кадра. Это временный ассет T02;
окончательная согласованная графика относится к T18.

В T03 земля, стены, прилавки и статичные маркеры ролей нарисованы кодом
`scripts/bazaar_ground.gd`, `scripts/bazaar_prop.gd` и `scripts/role_marker.gd`
специально для проекта. Это временная геометрия планировки без сторонних ассетов;
генератор и дополнительные изображения для запуска не требуются.

`items/*.svg` — семь собственных иконок 16×16 для T06, нарисованных
для проекта простыми фигурами без сторонних изображений. Готовые SVG включены
в репозиторий, генератор не нужен. Бандит/патрули и эффекты ударов T08–T10
нарисованы кодом проекта; это временные ассеты до T18.
